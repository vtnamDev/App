# Knowledge Base: Game Mode, Frame Pacing, Profiling, OEM Variants, UI Patterns

## Android Game Mode (`game-mode.md`)
- `cmd game mode [standard|performance|battery] <package>` and `cmd game set --mode 2 --downscale <ratio> --fps <rate> <package>` via `SHIZUKU_SHELL`.
- Read-back verification via `cmd game status <package>` or `dumpsys game_manager`.
