# UI Patterns (`knowledge/ui-patterns.md`)
- High-contrast obsidian telemetry theme (`#0B0F17` surface, `#00E5FF` electric cyan primary, `#FFB300` amber thermal warning, `#FF3D57` critical alert).
- Monospace numeric readouts (`JetBrains Mono`) paired with technical display headers (`Space Grotesk`) and clean body copy (`Inter`).
- Zero fake gauges: every metric displays its live source and confidence badge.
